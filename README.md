# Switzerland Railway Data Pipeline

This repository contains scripts to automatically download, process, and visualize railway network and schedule data for Switzerland. 

## Data Pipeline Overview

The data preparation pipeline is located in the `data_preparation/` directory and is designed to execute the following steps:
1. **01_download_infrastructure.py**: Downloads the latest OpenStreetMap (OSM) infrastructure data for Switzerland.
2. **02_extract_tracks_and_stations.py**: Parses the OSM data to extract relevant rail tracks and station locations.
3. **03_fetch_schedules.py**: Fetches in-depth schedule information for the network.
4. **04_visualize_network.py**: Generates visual maps and visualizations of the extracted network.
5. **05_build_network_graph.py**: Constructs a routable `.graphml` graph representing the network topography.
6. **06_download_gtfs.py**: Downloads and unpacks GTFS (General Transit Feed Specification) schedule files.

## Note on the `data/` Directory

By design, all raw and processed data generated by these scripts are saved into a `data/` directory at the project root. **The `data/` directory is excluded from version control.** 

We do this because:
- The data files are extremely large (the raw GTFS and OSM files can be several gigabytes in size).
- The data is generated deterministically by the code. It is better to version control the code that produces the data, rather than the data itself.

To reconstruct the data, simply run the scripts in the `data_preparation/` folder sequentially.
