# Switzerland Railway Data Pipeline 🇨🇭🚋

Welcome to the **Switzerland Railway Data Pipeline**! This project is a comprehensive toolkit designed to automatically download, process, model, and visualize railway network infrastructure and timetable data across Switzerland. 

Whether you're looking to build a network routing engine, analyze real-time schedule performance, or just visualize the incredible density of the Swiss rail network, these scripts do the heavy lifting of parsing complex OSM and GTFS datasets.

## 🛠️ Pipeline Steps in Detail

The pipeline is split into a series of sequentially numbered Python scripts located in the `data_preparation/` directory.

### 1. Infrastructure Download (`01_download_infrastructure.py`)
Fetches the latest OpenStreetMap (OSM) Protocolbuffer Binary Format (`.pbf`) export for Switzerland from Geofabrik. This provides the raw geographic footprint of the entire country.

### 2. Geographic Extraction (`02_extract_tracks_and_stations.py`)
Uses `pyrosm` and `geopandas` to parse the OSM data. It filters exclusively for railway infrastructure (standard rail, narrow gauge) and train stations/halts. The output is saved as two separate lightweight GeoJSON files: `switzerland_tracks.geojson` and `switzerland_stations.geojson`.

### 3. Real-Time Schedules (`03_fetch_schedules.py`)
Interfaces with the Swiss open transport API (`transport.opendata.ch`) to fetch live station departure boards for major hubs (Zürich, Bern, Basel, Genève, etc.). It compiles the data (train categories, destinations, operators, and platforms) into `switzerland_schedules.csv`.

### 4. Network Visualization (`04_visualize_network.py`)
Takes the extracted tracks and stations GeoJSON files and uses `matplotlib` to render a beautiful dark-themed, high-resolution geographic map of the entire network.

### 5. Graph Topology Building (`05_build_network_graph.py`)
Converts the flat track geometries into a topologically connected, directed routing graph using `NetworkX`. It preserves edges and nodes down to 15-decimal precision to maintain connectivity. Exports a `switzerland.graphml` file that can be used for pathfinding algorithms (like Dijkstra or A*).

### 6. GTFS Processing (`06_download_gtfs.py`)
The most intensive script in the pipeline. It:
- Downloads the massive official Swiss GTFS dataset.
- Unzips and processes `routes`, `trips`, `stops`, and `stop_times` files in memory-efficient chunks.
- Maps physical train attributes (weight, max speed, carriages, gauge, power supply) to specific routes based on `rolling_stock_profiles.json`.
- Outputs a highly detailed `in_depth_schedules.csv`.

## ⚠️ Why is the `data/` folder missing from GitHub?

By design, all raw and processed data generated by these scripts are saved into a `data/` directory at the project root. **The `data/` directory is explicitly excluded from version control via `.gitignore`.** 

**Why?**
1. **File Size**: The data files are extremely large. The raw GTFS and OSM files alone can exceed 3GB, vastly exceeding GitHub's 100MB file limit.
2. **Reproducibility**: The data is deterministically generated by the code. It is best practice to version control the *code that produces the data*, rather than the static data itself.

To reconstruct the data on your local machine, simply run the scripts in the `data_preparation/` folder in numerical order.

## 🚀 How to Run the Pipeline

### Prerequisites
Ensure you have Python 3.8+ installed. You will need to install the following spatial and data processing libraries:

```bash
pip install requests pandas geopandas pyrosm networkx matplotlib shapely
```

### Execution
Run the scripts sequentially from your terminal. Make sure you have a stable internet connection and plenty of RAM (especially for the GTFS script).

```bash
python data_preparation/01_download_infrastructure.py
python data_preparation/02_extract_tracks_and_stations.py
python data_preparation/03_fetch_schedules.py
python data_preparation/04_visualize_network.py
python data_preparation/05_build_network_graph.py
python data_preparation/06_download_gtfs.py
```

*Note: Script 06 involves downloading and merging gigabytes of data and may take several minutes to complete.*
